# 产品定位与范围

## 一句话

家长在家给小学二年级孩子做生词默写的**单机离线**小工具：家长读词、孩子在本子上写、家长批改；程序负责抽题、防偷看、记录错题。

## 唯一用户

家长（操作者）。孩子不操作电脑、不看屏幕，只在纸上书写。所有交互决策都以「家长一只手就能点完」为准。

## 核心价值排序

1. **录入快**：一本词表用整段粘贴，十分钟内搞定
2. **抽题对**：选的组、选的范围，一场内每个词只出现一次
3. **不偷看**：屏幕默认遮住词语，家长点一下才显示
4. **沉淀错题**：错词自动进错题本，连对够次数自动出本，不用人工维护

## 明确不做

- 语音识别、孩子在电脑上打字答题
- 账号、云同步、多设备
- 拼音显示/拼音输入（已确认排除）
- 游戏化激励（积分、排名、动画）
- TTS 语音朗读：**V2 才做**，V1 只留架构位

## 关键数字

| 项 | 值 |
|---|---|
| 单本词表规模 | 8~20 组，每组 10~30 词 |
| 词量上限假设 | 5000 词内保持 <1s 启动、<50ms 抽题 |
| 默认出本条件 | 连续答对 2 次（可设 1~3） |
| 默认遮罩时长 | 显示 3 秒后自动隐藏（可设 2~8 或关闭） |
